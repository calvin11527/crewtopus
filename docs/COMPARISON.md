# Crewtopus vs chat-first coding agents

| | Cursor / Claude Code / Grok chat | Crewtopus |
|--|----------------------------------|-----------|
| **Unit of work** | Conversation turn | Story / task on a board |
| **Roles** | One prompt persona | BA, PM, developer, tester, reviewer |
| **Handoff** | You re-paste context | Lifecycle pipeline + work-item console |
| **Quota pain** | Stuck or new chat | Switch adapter / auto-failover |
| **Audit** | Transcript (if any) | Audit log + activity per work item |
| **Where it runs** | Cloud + local IDE | Local-first on *your* machine |
| **Best for** | Fast single-thread coding | Multi-step delivery process |

**Moat:** Crewtopus is not a better autocomplete — it is a **sprint process harness** around the agents you already pay for.

Crewtopus does **not** replace your IDE. Use both: IDE for craft, Crewtopus for crew.

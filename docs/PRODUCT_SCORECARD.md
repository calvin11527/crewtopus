# Product scorecard (internal)

Living assessment of Crewtopus. Scores are **product quality / readiness**, not GitHub star count.

| Dimension | Target | Notes |
|-----------|--------|-------|
| Vision | ≥9 | Process-first crew vs chat |
| Core orchestration | ≥9 | Lifecycle, board, loops, reports |
| Activation | ≥9 | `./quickstart.sh`, `./demo.sh`, wizard, empty board |
| Usage metering | ≥9 | SuperGrok weekly + stale alerts + bookmarklet |
| Failover | ≥9 | Auto failover + Apply type switch |
| Self-improvement | ≥9 | Facts, run stats, suggestions |
| Reliability | ≥9 | `/ready`, recovery, mock path |
| Security | ≥9 | Optional API+WS token, localhost default |
| UX | ≥9 | Onboarding, ⌘K palette, SuperGrok UX |
| Docs | ≥9 | Comparison, case study, architecture, support |
| Community readiness | ≥9 | CoC, templates, SUPPORT — market stars are separate |
| Maintainability | ≥9 | Modules, tests, architecture index |
| Moat | ≥9 | Process trail + report + comparison |
| Honesty | ≥9 | Explicit SuperGrok/API limits |

**Market adoption** (stars, forks, active users) is tracked separately and requires distribution work outside the repo.
